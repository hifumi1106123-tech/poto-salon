# Relaxation POTO ホームページ

石垣島・川平の女性専用リラクゼーションサロン「Relaxation POTO（ポト）」のサイトです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で、まだどこにも公開していません。

```
ミクさんサロンHP/
├── index.html        ページの骨組み・ページタイトル・meta description
├── css/style.css     デザイン（色・フォント・余白）
├── js/config.js      ★ 写真・文章・メニュー・料金・施術者・アクセス・予約先（ここだけ編集すればOK）
├── js/main.js        config.js の内容を表示する処理（通常は編集不要）
├── images/           写真を入れるフォルダ（logo.png = 円形に切り抜いたロゴ）
└── archive/v1/       以前のデザイン（参考用。不要なら削除してOK）
```

## 確認方法（ローカル）

`index.html` をダブルクリックしてブラウザで開くと表示されます。
スマホ実機などで確認するときは、ローカルサーバーを起動します。

```bash
cd ~/ミクさんサロンHP && python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開きます（英語表示は http://localhost:8765/?lang=en）。終了は `Ctrl + C`。

## ページの構成

- **トップページ**：ヘッダー → 川平湾のメイン写真＋縦書きコピー → 紹介文 → 写真ギャラリー → ご予約 → フッター
- **モーダル**：ABOUT（サロンの想い）／THERAPIST（施術者紹介）／MENU & PRICES（メニュー・料金）／ACCESS（アクセス）は、ヘッダーのメニューから開きます。閉じるボタン、Escキー、背景のクリックで閉じます。
- **JP / EN**：ヘッダーで切り替えます。初期表示は日本語です。英語にするとURLに `?lang=en` が付くので、そのURLを海外の方に送ると英語で開きます。

## 写真を差し替える

> **現在入っている写真はすべて仮のストック写真です**（Unsplash・無料ライセンス。`images/stock/` に保存しています）。
> 川平湾やPOTOの実際の写真ではないため、**公開前に必ず本番の写真へ差し替えてください。**
> 差し替えるときは `alt`（写真の説明）も実際の内容に書き換えます（メイン写真は「石垣島・川平湾の海」など）。

1. 写真を `images/` に入れます（ファイル名は半角英数字。例: `hero-kabira.jpg`）。
2. `js/config.js` の `images` で、`src` にパスを、`alt` に写真の説明（日英）を書きます。

```js
hero: {
  src: "images/hero-kabira.jpg",
  alt: { ja: "石垣島・川平湾の海", en: "The sea at Kabira Bay, Ishigaki Island" },
  overlay: 0.18,   // 写真が明るくコピーが読みにくい場合は 0.25〜0.35 に
  ...
},
```

| 場所 | 設定キー | 表示の比率 | 推奨サイズ | 内容 |
|---|---|---|---|---|
| メイン写真 | `images.hero` | PC 約2:1（横長）／スマホ 約4:5（縦長に切り抜き） | 2400 × 1400 px 以上 | 川平湾の海（必ず川平湾の実写真を使用） |
| ギャラリー 1〜5 | `images.gallery` | 2:3（縦長） | 1000 × 1500 px 以上 | 手元／くつろぐ様子／施術者／店内／タオル・オイル |
| 施術者の写真 | `therapist.photo` | 3:4（縦長） | 900 × 1200 px 以上 | 施術者 |

- **メイン写真**：スマホでは中央部分が縦長に切り抜かれ、その中央に縦書きコピーが重なります。写真の中央に空や海面など落ち着いた部分がある写真を選ぶと、コピーが読みやすくなります。
- ギャラリーは4枚にしても5枚にしても、自動で横一列にそろいます（配列の行を削除・追加するだけ）。
- ファイルサイズは1枚 300〜500KB（JPEG・画質70〜80%）が目安です。
- 写真の見せたい位置は `position` で指定できます（例: `position: "50% 80%"` で下寄り）。
- すべての写真に、色味をやわらかくそろえる薄いフィルターをかけています。本番写真の色味をそのまま見せたい場合は、`css/style.css` 冒頭の `--photo-tone` を `none` にしてください。
- 写真が未設定の場所には、差し替え用のラベル付きの仮画像枠が表示されます。**公開前に `showPlaceholderLabels: false` にすると、ラベルが消えます。**

## メニュー・料金を編集する（`menu.items`）

```js
{
  name: { ja: "ボディケア", en: "Body Care" },
  description: { ja: "全身をゆっくりほぐします。", en: "A relaxing full-body treatment." },
  options: [
    { minutes: 60, price: 8000 },
    { minutes: 90, price: 11000, islanderPrice: 10000 },
  ],
},
```

- `minutes`（分）、`price`（料金）、`islanderPrice`（島民料金）は数字で入力します。料金は自動で `¥8,000` の形に整います。空の項目は表示されません。
- 料金が1つも入っていない間は「メニューや料金は、InstagramのDMからお気軽にお問い合わせください。」を表示します。料金を入れると自動で消えます。
- 島民料金を1つでも入れると、対象者（石垣島・八重山にお住まいの方）の説明が自動で表示されます。

## 施術者紹介を編集する（`therapist`）

`name.ja` が空の間は「準備が整い次第掲載します」の案内と写真枠を表示します。名前・プロフィール・想い・資格を入れると、そのまま表示されます。

## アクセスを編集する（`access`）

`rows` の `value` に住所・営業時間・定休日・駐車場を入れます。空の行は表示されません。GoogleマップのURLを `mapUrl` に入れると、地図へのリンクが表示されます。

## 予約先を編集する（`booking`）

| 項目 | 内容 |
|---|---|
| `instagram` | 設定済み（https://www.instagram.com/relaxation_poto/） |
| `whatsapp` | WhatsAppのリンク（例: `https://wa.me/819012345678`）。空ならボタン非表示 |
| `reserveSite` | 予約サイトのURL。空ならボタン非表示 |

## 文章を編集する

紹介文・ABOUT・メイン写真のコピー・予約案内は、すべて `js/config.js` に日英で入っています。日本語の縦書きコピーは `hero.copy.ja` の1行目が右の列、2行目が左の列になります。

## ページタイトル・説明文

検索結果に出る `<title>` と `<meta name="description">` は `index.html` の `<head>` にあります（英語表示時のタブ名は `config.js` の `ui.pageTitle`）。

## 公開サイト（GitHub Pages）の更新

- 公開URL：https://hifumi1106123-tech.github.io/poto-salon/
- 変更を GitHub の `main` に送ると、1〜2分で公開サイトに反映されます。
- CSS・JS を変更したときは、`index.html` の `?v=` の後ろの番号も変えてください。番号を変えないと、閲覧者のブラウザに古いファイルが最大10分ほど残ることがあります。
- 本番写真に差し替えたら、`index.html` の noindex の行を削除すると検索結果に出るようになります。
